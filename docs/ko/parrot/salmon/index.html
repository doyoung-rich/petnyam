앵무새 연어 먹어도 될까? 종·조리 방식부터 확인

모든 앵무새에게 연어가 안전하다고 단정할 근거는 확인하지 못했습니다. VCA의 마코앵무 식단 안내에는 가끔 소량의 익힌 생선이 언급되지만, 연어 자체나 모든 앵무새 종의 급여량을 검증한 자료는 아닙니다.

생연어·훈제연어도 같은가요?

아닙니다. 익힌 생선에 대한 설명을 생연어·훈제 제품·양념 요리에 그대로 적용하지 마세요. 종 이름과 제품 성분·조리 상태를 적어 조류 진료 수의사에게 확인하세요.

이미 먹었다면 무엇을 알려야 하나요?

먹은 제품, 추정량, 시각과 현재 상태를 기록하세요. 호흡이나 행동의 이상이 있으면 온라인 답변을 기다리지 말고 병원에 연락하세요.
