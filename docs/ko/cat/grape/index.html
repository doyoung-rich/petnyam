고양이 포도 먹어도 될까? 급여하지 않는 편이 안전

Cornell은 고양이에게 피해야 할 사람 음식 목록에 포도와 건포도를 포함합니다. 이 권고를 따르되 강아지의 중독량·사례를 고양이의 정확한 안전량으로 바꾸어 제시하지 않습니다.

한 알이면 괜찮나요?

이 페이지에서는 안전한 알 수를 정하지 않습니다. 포도·건포도와 이를 포함한 제품을 간식으로 권하지 않습니다.

이미 먹었다면?

종류·추정량·섭취 시각과 현재 상태를 기록해 수의사에게 상담하세요. 집에서 임의로 구토를 유도하지 마세요.
