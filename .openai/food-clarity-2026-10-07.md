# Food clarity release — 2026-10-07

Scope: 50 foods × 5 animal groups × Korean/English = 500 existing public pages. Original user edits in other checkouts were not included or discarded. GitHub Pages `/docs`, domain, AdSense/affiliate settings, articles and URL paths remain in place.

## Reader-facing changes

Decision and plain-language answer appear first; jump links lead to reasons, preparation, exclusions, ingestion records and sources. All 250 combinations have bilingual content. Existing detailed priority explanations and linked sources remain visible. “Do not feed” separates toxicity from dietary unsuitability; “unknown” means do not claim either toxicity or safety. A permission for a prepared plain ingredient is not permission for processed products.

Records identify direct food/species guidance, dietary category application, or limited evidence. Species-specific uncertainty is preserved rather than copying dog hazards to cats, rabbits, hamsters or birds. No numerical safe doses, diagnosis, personal outcome or veterinary review is claimed. Rabbits' urgent signs focus on eating/droppings rather than vomiting. Fruit guidance is occasional, not unrestricted feeding. Parrot is a broad group and exact bird species still matters.

Primary animal-welfare/veterinary sources are linked within records. Shared category text is authored once, with original food-specific applications; no long source quotation is reproduced. Food spelling/cultivar uncertainty includes Napa cabbage and kabocha versus generic cabbage/pumpkin guidance.

## Whole-site findings

1. Previously prominent “safe” labels conflicted with incomplete explanations. The new renderer, homepage cards and both search controls use the same record status.
2. Shopping appeared before key reading guidance. Existing shopping is preserved but placed after the guide/method sections.
3. Headline counts/dates were stale and ambiguous. The homepage now identifies food topics, animal groups, recommendation types and the content-update period.
4. Food pages previously relied on a router that replaced static content. Native food navigation and a static-content marker preserve the actual deployed article; food-language switches load the matching document.
5. Some exact food/species combinations remain weakly evidenced, especially hamster/bird details. The release is readability and evidence-scope improvement, not universal veterinary approval. Some English guide/policy destinations remain Korean and are labeled where linked from food explanations.

## Verification

500-page checks cover all records, decisions, headings, sections, source URLs, language/canonical metadata and modified date. Existing guide, site-map and priority-topic checks run in addition. Preview tests cover 390px mobile layout, selected-animal search, bottom search and language switching. No account/private Search Console indexing status has been assumed.
