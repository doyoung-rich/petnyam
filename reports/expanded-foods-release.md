# 과일·고기 상세 안내 추가

2026-10-31. 사용자가 기존 UX 개선 배포와 음식 콘텐츠 확장을 승인했다. 기존 UX 개선은 `ca325244`로 main에 반영됐으며 GitHub Pages 배포 성공과 실제 공개 화면을 확인했다.

이번 추가분은 한글·영문 4개 주제, 8페이지다. 짧고 비슷한 조합 페이지를 대량으로 만들지 않고 음식별 단락으로 바로 연결한다.

|주제|추가한 검색 항목|자료 범위|
|---|---|---|
|강아지 과일|귤, 캔털루프 멜론, 허니듀, 블랙베리, 크랜베리, 코코넛, 파파야, 천도복숭아|AKC와 수의사가 작성·검토한 PetMD의 식품별 안내. 다른 동물에게 판정을 확장하지 않음|
|삼겹살|삼겹살|강아지 돼지고기 안내, 강아지·고양이의 식품 위생과 영양 균형 원칙, 농사로 지방 기록|
|소고기 부위|안심, 등심, 채끝, 양지, 우둔·홍두깨살, 갈비|정확한 원료명·등급·생것/조리 상태를 남긴 농사로 자료와 부위별 확인사항. 안전 순위가 아님|
|다짐육|다짐육·다진 소고기|무양념 고기와 가공 패티 구분, FoodSafety.gov의 통고기/다짐육 가열 기준과 반려동물 식단의 차이|

기존 키위·라즈베리 2개를 포함하면 보충 검색 항목은 18개다. 이번에 추가된 것은 과일 8개와 고기·부위 8개, 총 16개다. 기존 50개 기본 음식/500개 언어별 상세 페이지는 판정값과 본문을 보존했다.

## 연결

- 홈 검색창과 하단 검색창: 기존 원본 `site-static/convenience.js` 및 배포용 `docs/convenience.js`에 동일한 검증된 검색 메타데이터를 생성한다.
- 상세 페이지의 이어서 검색: 같은 추가 검색 원본을 재사용한다.
- 과일은 해당 과일 단락으로, 소고기 부위는 해당 부위 단락으로 연결한다. 삼겹살·다짐육은 안내 글 맨 위로 연결한다.
- 기존 강아지·고양이 돼지고기/소고기 페이지에 부위·조리 상태 안내 링크를 추가했다.
- 음식 목록 상단에서 새 항목을 찾을 수 있고, 홈에는 새 과일·소고기·삼겹살 가이드 카드를 표시한다.
- 농사로 원료 검색은 링크의 고기 이름을 미리 채운다. 검색어를 새 분석 서비스에 보내거나 브라우저 저장소에 기록하지 않는다.

## 정확성과 검증

농사로의 원료번호·원료명·지방 수치를 원자료와 대조한다. 등급이나 조리 상태가 다른 기록을 같은 조건의 실험처럼 비교하지 않으며, 성분 비율을 개별 급여량이나 안전 보증으로 사용하지 않는다. 생것이라는 자료 표시는 생고기 급여 권장이 아님을 명시했다.

소·돼지 다짐육의 71°C, 해당 통고기의 63°C와 3분 휴지는 미국 사람 음식 취급 기준표임을 밝히고, 이를 반려동물 식단 처방이나 양념 제품의 적합성으로 바꾸지 않는다. 운영자 반려동물에게 직접 먹인 경험이나 수의사 감수를 지어내지 않았다.

자동 검사: 8페이지의 제목·설명·언어·출처·canonical, 모든 검색 목적지와 단락, 종별 검색 제한, 원료 기록 원본 일치, 원본/배포용 실제 검색 함수 동작을 확인한다. 기존 500페이지, 저장, 나이 계산기, 홈 공고, 원료 검색, 제휴 추천 중지 상태의 회귀 검사를 수행한다. 사이트맵은 544개 URL, 전체 HTML은 545개다.

브라우저 확인: 귤 검색 → 귤 손질 단락, 삼겹살 검색 → 지방 비교와 농사로 검색, 고양이 상세의 등심 검색 → 등심 설명, 모바일 비교표의 가로 스크롤과 문서 너비, 영문 과일 안내를 확인했다. 실제 공개 환경의 검색순위·체류시간 개선을 측정한 결과는 아니다.
